ANOMALY DETECTION PLATFORM

A streaming service that flags anomalies in live event data, built on Kafka and async
FastAPI. I prototyped an LSTM autoencoder, containerized the service with Docker, and
deployed it to Kubernetes with CI/CD in GitHub Actions.

Suggested skills: Python, Apache Kafka, FastAPI, PyTorch, Docker, Kubernetes, CI/CD


ROCKETDOCS

RocketDocs is an AI powered code documentation generator that lets you create and talk to
your documentation. I built the single page React front end in TypeScript and TailwindCSS,
and added doc templates and a review queue.

Suggested skills: TypeScript, React.js, TailwindCSS, Single Page Applications, Git


PWDLY

Pwdly is a web and mobile password manager with vault encryption and master password
gating. I co-built it with a teammate in React Native and Expo, sharing components across
mobile and web.

Suggested skills: React Native, Expo, JavaScript, React.js, Mobile Application Development


HID BEHAVIOR DETECTOR

A Linux tool that flags suspicious command execution after a new USB keyboard is attached.
It collects process and HID events with bpftrace and udev, scores them in a C++ analyzer,
and surfaces explainable reports in a desktop app.

Suggested skills: Python, C++, Linux, eBPF, CMake, Threat Detection


N-BODY PARTICLE RENDERER

A real time 3D gravitational simulation of 2,000 particles in C++17 and OpenGL 3.3. I wrote
the O(n^2) physics core and render pipeline by hand and verified accuracy with energy
conservation checks.

Suggested skills: C++, OpenGL, GLSL, CMake, 3D Graphics


CARDGAME2D

A Balatro inspired 2D card game in C++ and SDL3 with poker style scoring. Players select,
play, and discard cards against real time scoring and animations, built with CMake and
shipped as a Windows release.

Suggested skills: C++, SDL, CMake, Game Development, Git
